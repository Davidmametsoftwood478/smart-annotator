## 🛠️ How it Works

The software operates through a simple three-step workflow.

### Step 1: Import Files
Open the application and click the Import button. Select the folder containing your AI-generated text files. The app supports standard markdown files and plain text documents. It lists every file found in the sidebar.

### Step 2: Add Annotations
Click on any file to open the editor. You can highlight specific sections or add comments directly into the text. Use the label tool to group sections by topic or quality level. The app saves your work automatically as you type.

### Step 3: Run AI Revision
Once you label your edits, click the Sync button. You must provide an API key from your preferred AI provider. The system reads your annotations and sends the document to the AI. The tool replaces your draft with an improved version based on your notes. You can compare the original and the new version side-by-side before you sign off on the changes.

## ❓ Frequently Asked Questions

**Does the software store my data on a server?**
No. Your documents stay on your computer. Only the text you send for revision leaves your machine during the sync process.

**Can I undo my changes?**
Yes. The software creates a backup folder inside your project directory. You can access previous versions of your text if the AI output does not meet your expectations.

**Which AI models are supported?**
The tool supports major large language models. Check the settings menu to see the current list of available providers, such as Claude or ChatGPT.

**What happens if the internet cuts out while I work?**
Your local edits remain safe. The sync process will pause until you reconnect to the network.

**How do I update the application?**
The software checks for updates upon launch. If a new version exists, it prompts you to download the latest installer.

## 📈 Troubleshooting

If the software fails to launch, try these steps:

1. Restart your computer to clear pending file locks.
2. Run the installer again to repair missing components.
3. Ensure your internet firewall allows the application to communicate with your AI provider.
4. Check that your API key is correct in the settings menu.
