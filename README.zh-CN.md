# 🖍️ 智能批注器 Smart Annotator

**对 AI 产出物批量批注，再让 AI 一次性改完。**

[English](README.md)

AI 初稿很少能直接用。常见的循环是：看到一个问题 → 提一次 → 等 → 看到下一个 → 再提一次。十个问题十个来回，而且每改一轮都可能顺手弄坏本来没问题的地方。

这个工具把顺序反过来：像给文档加批注一样把整份稿子标一遍——划词、整段、圈住一张图表——批注先**累积**，最后**一次性**提交。改完你会拿到一份逐条回执，告诉你哪几条真的生效了。

## 为什么不直接在对话里说「帮我改这 8 处」

因为指令一密集，模型就会漏。[指令遵循基准测试](https://arxiv.org/abs/2507.11538)发现，前沿模型在高指令密度下准确率只有 **68%**，并且存在明显的**位置偏置——靠前的指令执行得更好**。也就是说，你列在后面的批注，是最容易被悄悄跳过的。

这个工具从两头堵：

- **每条批注都有锚点。** 不是「开头太长了」，而是绑定到具体文本、真实单元格地址（`Sheet1!B3`）或页码。锚点消除歧义，模型就不容易飘。
- **每条批注都会核验。** 改完之后，工具逐条比对实际文本，给出「8 条中 6 条检出改动」。没生效的两条可以一键基于新版重新提交。

没有核验的批量修改是在赌运气；有了核验，它才只是「更快」。

## 两种用法

### 一、单文件独立使用 —— 免安装、可离线

下载 **[`skills/smart-annotator/assets/annotator.html`](skills/smart-annotator/assets/annotator.html)** 双击打开就是全部。没有服务端、不用构建、不用登录，字体和依赖库全部内联，不联网。

直接支持 **Markdown、HTML、纯文本、CSV、图片**。

### 二、作为 Claude plugin —— 丢个文件说「批注这个」

把本仓库装成 plugin（见下），流程就变成：

1. 你说「**批注这个文件**」并附上 `.docx` / `.xlsx` / `.pdf` / `.pptx` / `.md` / 图片。
2. Claude 把它转成可批注视图，把工具发给你。
3. 你批完点「**导出批注单**」，把文件拖回对话。
4. Claude 逐条改完，**按原格式**把文件还给你。

Word / Excel / PDF / PPT 的支持就是这么来的——转换跑在 Claude 侧，单文件才能保持轻量离线。

## 能批注什么

| 类型 | 怎么批 | 记录的锚点 |
|---|---|---|
| 文字 | 选中即可 | 引用原文 + 块序号 |
| 整段 / 块 | 悬停点 💬 | 块序号 |
| 视觉区域 | 点 **▭ 圈选** 拖框 | 底层 HTML + 区域截图 |
| 表格单元格 | 点单元格 | **真实地址** —— `Sheet1!B3`，跨格为 `B2:D5` |
| PDF / 幻灯片 | 在页面上拖框 | **真实页码** |

带脚本的**可交互 HTML 会真正运行**：页面在 iframe 里渲染，你可以点到目标状态**再**批注。

## 功能

- **三种批注方式** —— 划词高亮、整段、自由圈选
- **批量提交** —— 全部批注汇成一份结构化批注单，而不是一处一个 prompt
- **逐条回执** —— 核验哪些批注真的产生了改动，未生效的可一键重提
- **逐条采纳** —— 每处改动可单独接受/拒绝，像代码评审
- **多文档** —— 多个文件分标签同时批注，导出合并成一份批注单
- **真实结构锚点** —— Excel 单元格地址、PDF/幻灯片页码
- **自动保存与恢复** —— 刷新不丢；批注包可回载继续批
- **中英双语** —— 跟随浏览器语言（中文环境自动中文，其余为英文），可一键切换并记住选择；批注单跟随界面语言
- **自带 AI 或不用 AI** —— 可填 Anthropic / 任意 OpenAI 兼容端点的 Key 直接出结果，也可以只导出批注单粘到任何地方

## 安装为 plugin

在 Claude Code 或 Claude Cowork 里执行：

```
/plugin marketplace add USERNAME/smart-annotator
/plugin install smart-annotator@annotator-tools
/reload-plugins
```

就这样——**构建产物已随仓库提交，不用克隆、也不用构建**。以后更新用 `/plugin marketplace update annotator-tools`。

处理 `.docx` / `.xlsx` / `.pdf` / `.pptx` 时，转换脚本需要：

```bash
pip install -r requirements.txt
# .pptx 逐页渲染还需要系统安装 LibreOffice（`soffice` 在 PATH 中）。
# 缺失时会自动退回「逐页文字视图」。
```

Markdown、HTML、CSV、纯文本、图片不需要这些。

## 从源码构建

只有改了 `src/annotator.template.html` 才需要。

```bash
npm install
npm run build     # 产物 -> skills/smart-annotator/assets/annotator.html
```

构建会把 `marked`、`html2canvas` 和两个 woff2 字体内联成单文件，并在任何占位符未替换时直接报错退出。

## 批注包是开放格式

每次导出都可以存成 JSON——原文、全部批注、锚点、圈选截图（base64）。格式见 **[docs/annotation-pack.schema.json](docs/annotation-pack.schema.json)**，你完全可以接自己的流水线，不必用 Claude。这里没有锁定。

## 已知限制

如实写出来，因为它们是真的：

- **回执核验是启发式的。** 它比对引用原文是否还原样存在。像「在这句后面补个出处」这种本就不改动原句的批注，会显示成"未检出改动"——界面上写明了这一点，请自行确认那几条。
- **`<canvas>` 图表改不了。** 截图能拿到像素，但背后没有可改的 HTML。SVG / HTML / CSS 做的可视化没问题。
- **html2canvas 不是浏览器。** 复杂 CSS、跨域图片、部分自定义字体在区域截图里还原不完美。
- **截图不随文本回传。** 把 `.md` 批注单拖回对话会带上批注和底层 HTML 片段，但不含图片。需要模型"看到"该区域时，请用 JSON 批注包。
- **二进制格式的回写取决于文档处理能力**，复杂排版（合并单元格、幻灯片母版、重排版 PDF）是最容易出偏差的地方。
